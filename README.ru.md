# backpack-code

Мак работает закрытым в рюкзаке, рулишь им с телефона.

macOS исходит из того, что закрытая крышка = спящая машина. Если нужно
обратное - ноут продолжает работать, остаётся доступным и живёт день в
сумке - придётся продраться через несколько неочевидных деталей. Эта репа и
есть результат: пять launchd-агентов и шесть шелл-скриптов, без зависимостей
сверх того, что уже есть в macOS.

Замер за ночь: **93% -> 69% за 8.3 часа** (2.89%/ч, ~35 часов от полного
заряда), ноль событий сна за 100 замеров.

## Состав

| Файл | Что делает |
|---|---|
| `bin/sleep-toggle.sh` | Включает и снимает запрет сна (`pmset disablesleep`). Вешается на хоткей - смысл в том, чтобы взвести машину одним нажатием перед тем, как убрать её в сумку. |
| `bin/backpack-mode.sh` | Раз в 30 сек: если крышка закрыта **и** сон запрещён - морозит тяжёлые приложения через SIGSTOP и гасит панель. Замер: 149% CPU -> 6%. |
| `bin/battery-watch.sh` | Пуши о разряде на телефон при 30/20/10/5% через [ntfy](https://ntfy.sh) или Telegram. |
| `bin/backpack-health.sh` | Раз в 30 мин проверяет остальные агенты и поднимает упавших. Агенты присматривают друг за другом, поэтому лечь должны сразу оба. |
| `bin/sleep-audit.sh` | Отвечает на «спал ли мак за N минут и что держит его бодрым». |
| `bin/night-log.sh` | Необязательная телеметрия в CSV: заряд, события сна, число замороженных процессов. |

Отдельным необязательным агентом под launchd держится remote control
[Claude Code](https://claude.com/claude-code) - ради этого всё и затевалось:
рулить кодинг-агентом с телефона, пока ноут закрыт.

## Установка

```bash
git clone https://github.com/bughouse-wizzard/backpack-code
cd backpack-code
./install.sh
```

Установщик кладёт скрипты в `~/bin`, рендерит плисты под твоего пользователя,
генерирует приватный топик ntfy, ставит правило sudoers (чтобы тумблер сна не
спрашивал пароль - из хоткея спросить некому) и загружает агенты.
Идемпотентен.

**Дальше открой `~/.config/backpack-mode.conf` и впиши свой VPN-клиент в
`NEVER_FREEZE`.** Замороженный VPN за закрытой крышкой не чинится: связи с
машиной больше нет, а разбудить её некому.

Снять всё, с разморозкой того, что осталось в SIGSTOP, и возвратом сна:

```bash
./uninstall.sh            # --purge снесёт ещё конфиги и правило sudoers
```

### Повесить тумблер на хоткей

Заскриптовать это нельзя - у Shortcuts нет импортируемой формы, которая
пережила бы чужое имя пользователя. Поэтому пять кликов, один раз:

1. Открыть **Shortcuts** (Быстрые команды), создать новый шорткат.
2. Добавить действие **Run Shell Script** (Запустить скрипт).
3. Shell - `/bin/bash`, вставить **абсолютный** путь, его печатает установщик:

   ```
   /Users/<ты>/bin/sleep-toggle.sh
   ```

   `$HOME/bin/...` здесь не сработает: Shortcuts запускает скрипты с пустым
   `$HOME` и без `/usr/sbin` в `PATH`, а там лежит `ioreg`.
4. Назвать (например, «Контроль сна»), выбрать иконку.
5. В настройках шортката (значок ⓘ справа) назначить сочетание клавиш.
   Оснастка строилась вокруг `^⌥S`.

Дальше этим хоткеем машина взводится прямо перед тем, как уехать в сумку, и
им же отпускается, когда её достали.

Две вещи, которые выглядят как поломка скрипта, но ею не являются:

- **В macOS 26 «Pin in Menu Bar» из Shortcuts убрали** - раздела Menu Bar в
  боковой панели больше нет. Гайды с иконкой в меню-баре написаны до неё;
  остались хоткей, Spotlight и Quick Actions.
- **Уведомления через `osascript` не проходят** песочницу Shortcuts. Чтобы
  увидеть результат, подключи действие Show Notification к Shell Script Result.

Подробнее - в [docs/ru/sleep-toggle.md](docs/ru/sleep-toggle.md).
