# backpack-mode - режим рюкзака

*[English version](../en/backpack-mode.md)*

Пока крышка закрыта и включён запрет сна, тяжёлые приложения заморожены, а
панель обесточена. Открыл крышку - всё вернулось.

## Файлы

- `~/bin/backpack-mode.sh` - логика
- `~/.config/backpack-mode.conf` - списки приложений
- `~/Library/LaunchAgents/com.backpack.backpack-mode.plist` - агент, раз в 30 сек
- `~/.local/state/backpack-frozen.pids` - какие PID заморожены сейчас
- `~/Library/Logs/backpack-mode.log` - лог

## Команды

```bash
~/bin/backpack-mode.sh status    # режим, крышка, заморожено, подсветка
~/bin/backpack-mode.sh targets   # кого заморозило бы, ничего не трогая
~/bin/backpack-mode.sh thaw      # отпустить немедленно
~/bin/backpack-mode.sh freeze    # заморозить принудительно
```

## Как устроено

Условие срабатывания - **оба сразу**: запрет сна включён и крышка закрыта.

Заморозка через `SIGSTOP`: процесс останавливается намертво, память остаётся,
`SIGCONT` возвращает его в то же состояние. Ничего не убивается и не теряется.
Замер на живой системе: цели жрали 149% CPU, после заморозки 6%.

## Два неочевидных решения

**Чёрный список, а не белый.** Замораживаем перечисленное, а не «всё кроме
нужного». Белый список однажды заморозил бы VPN: клиенты сплошь и рядом не
выглядят VPN-клиентами по имени, часть живёт не в `/Applications`, а часть -
вообще системные расширения. С закрытой крышкой такое не чинится, только
доставать ноут. Поэтому свой VPN обязательно вписывать в `NEVER_FREEZE`.

**Крышка, а не экран.** Детектор - `AppleClamshellState` из `ioreg`.
Ассерта powerd `Prevent sleep while display is on` для этого НЕ годится: в
clamshell она не снимается и висит часами, показывая экран включённым.
Проверено 2026-09-01 - висела 54 минуты при закрытой крышке, из-за чего
заморозка вообще не запускалась.

## Гашение панели

`disablesleep` глушит сон целиком, включая сон дисплея, поэтому за закрытой
крышкой панель остаётся под напряжением и светит в пустоту.

Гасим через `pmset displaysleepnow` - работает без пароля, обесточивает
подсветку (`IOMFBBrightnessLevel` уходит в 0) и не усыпляет систему. Яркость в
ноль не подходит: она лишь приглушает, питание остаётся.

Команда идемпотентна и зовётся на каждом прогоне при закрытой крышке, так что
если что-то разбудит экран - погаснет снова, максимум через 30 секунд.

## Разморозка: три независимых пути

1. агент при следующем прогоне - открылась крышка или снят запрет сна
2. `sleep-toggle.sh off` - при выключении режима
3. руками: `backpack-mode.sh thaw`

Чтобы процессы остались замороженными, должны отказать все три.

## Отказ в безопасную сторону

Если состояние крышки прочитать не удалось, она считается открытой и заморозки
не происходит. Лучше не сэкономить заряд, чем заморозить не вовремя.
